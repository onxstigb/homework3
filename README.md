# Savor & Simmer

Savor & Simmer is a dynamic cooking website created for N315 Homework 3.

## About

This website features recipes, cooking tips, information about the site, and contact information.

The site was created using HTML, JavaScript, MVC architecture, and SCSS.

## Pages

- Home
- Recipes
- About
- Tips
- Contact

## Technologies

- HTML
- JavaScript
- MVC
- SCSS
- GitHub

## Features

- Dynamic page injection
- URL/hash-based navigation
- Five separate views
- Responsive design
- Images and text on each page
